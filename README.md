# Famms — оригінальний шаблон (без змін)

Безкоштовний HTML-шаблон інтернет-магазину **Famms** від [HTML.DESIGN](https://html.design/download/famms-ecommerce-html-template/), завантажений без жодних змін.

На його основі створено навчальний лендінг магазину кросівок **BLESS PRIME**:

- відредагований лендінг: https://mariasheva05.github.io/Shevchenko-Mariia_35-1/
- репозиторій лендінгу: https://github.com/MariaSheva05/Shevchenko-Mariia_35-1
